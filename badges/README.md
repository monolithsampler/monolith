# Machine badges (not included)

Each machine's MAIN panel and the MPC Studio's screen can show a badge image. The original logos belong to their
makers, so none come with Monolith; without them the machine's name is shown in text.

To use your own, put PNGs here (transparent background works best):

| File | Where it shows |
|---|---|
| `MPC60.png`, `MPC3000.png`, `MPC2000XL.png`, `SP-1200.png`, `ASR-10.png` | the machine's MAIN panel |
| `MPC60_top.png`, `MPC3000_top.png`, `MPC2000XL_top.png`, `SP-1200_top.png`, `ASR-10_top.png` | the top strip / the Studio screen |

Restart Monolith after adding them. Files in this folder (other than this README) are ignored by git, so they stay on
your machine.
